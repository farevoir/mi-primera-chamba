# Track applications

Keeps `my-data/applications.md` current and turns it into a short status report. Vocabulary in `GLOSSARY.md`.

## Steps

1. **Read `my-data/applications.md`**, including the status words listed at the top of the file.

2. **Apply news.** For each update the user reported, change the matching row's status and add a dated note. If more than one row could match, ask which one. Done when every reported update is in the file.

3. **Report**, in one short screen:
   - Count per status.
   - **Follow-up due**: rows "applied" 14+ days ago with no later news. Offer to draft a short, polite follow-up message; the user sends it.
   - **Interviews**: point to that posting's `my-data/jobs/<folder>/job.md` talking points and offer to prepare questions.
   - **To verify**: links the user can check by hand.
   - **Ready to tailor**: "new" rows at or above the tailored-CV threshold with no CV yet; offer `tailor-cv`.
